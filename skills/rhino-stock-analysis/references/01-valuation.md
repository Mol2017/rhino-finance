# 估值：前瞻估值“年度价值交易区间”

来源：17 期会员估值教学（02、26、27、56–61、69、79、87、88、116、177、237、261、305），以及会员第 183 期（2024-02）、第 311 期（2026-11）每周估值表。

核心：**股价 = PE × EPS**。EPS 是理性的，可以前瞻量化；PE 是情绪，不预测，只看它正常的波动范围（61、58）。估值决定**值不值得买、大概在哪买**，具体价位交给技术面：“基本面先行，技术面确认”（61）。

## 0. 先判断能不能用估值

- 日内短线不用；做价值或持有一段时间才用（57）。
- 只做标普、纳指、纳指综合成分股。日成交额只有几十万美金的，任何形态都无效（27）。
- 共识要可信：覆盖的分析师多。刚 IPO、小型、业务多变的公司不做预测（177）。

## 1. 按公司类型选工具

| 类型 | 用什么 |
|---|---|
| 盈利稳定 | PE（主方法） |
| 重资产或周期：银行、保险、地产、REIT、钢铁、能源 | PB，二选一时比 ROE（60） |
| 未盈利但营收高增长 | PS：和业务最像的同行比，再和自身历史 PS 比，只判断方向（88、116、61），见第 3 节末 |
| 负现金流的早期成长股 | 没法估值，按风险回报小仓位做（88） |
| 衰退型（下财年 EPS < 本财年） | 没建仓的不考虑；PEG、ERP、CAPM 都不适用 |
| 大宗商品、生物医药、中小医药 | 能力圈外，只看技术面或不碰。药物研发和审批流程看不懂的医疗股都算（69）；不熟悉的行业只做技术面投机（183） |

几种方法都能用时，**选区间最窄的那个**：PE 算出 80–300 没用，PB 算出 90–120 才能用（60）。

## 2. 主方法：年度价值交易区间（79、183、311）

1. **取两年共识 EPS（Non-GAAP，Normalized）**：当前财年和下一财年。
   - 非 12 月财年要换算：代码后的数字是财年截止月（CSCO 7 = 7 月；PG、EL 到 6 月）。
   - 当前财年只剩一个季度左右时（如 12 月财年的 11 月），主区间用下一财年；市场开始交易下一财年时，买点跟着上调（292）。
   - 剔除离谱的最高、最低预测（305）。卖方增速要自己打折（177：FactSet 34.5%，他用 20.1%）。
   - 口径前后一致：EPS 用 Non-GAAP，PE 区间也用 Non-GAAP（79）。
2. **看 EPS 修正方向**：比较现在和 7/30/60/90 天前的预测，再看上调和下调的分析师家数（177、305）。
   - 看下调**幅度**，不看次数（237）。
   - 非财报日改前瞻，等于提前放利空（177）。
   - 下一财年 EPS < 当前财年 = **衰退型**。
3. **定 PE 区间**：
   - **默认**：用该股 2018–2019 年 PE 的低位和高位，中位 PE = 两者平均（79）。
     - 选这两年是因为当时的经济和货币环境和之后几年相近；2020 年永远不用。
     - 2026 年表头写的是“PE(历史波动)”。
   - **成长股**用整数档：20–30、30–40、40–60。
   - **以下情况改用别的 PE（79）**：
     - **曾是超高成长、现已成熟**（NFLX 18–19 年 PE 91–263，会算出几千块）：改用和增速匹配的正常 PE，约 20% 增速对应 **25–30 倍**。
     - **公司地位或增速变化**：主动调整档位（2026 年 NVDA 30-40→20-30，INTU 20-30→15-25，TTD 27-45→20-30，AMAT 15-25→20-30）。
   - **交叉核对**：
     - 行业常见 PE：传统车企 10–20，大型科技 30–40，超高成长 ~150（02）。
     - 和利率环境相同的年份比：零利率比 2014 年，2% 利率比 2018 年（61）。
   - **2021 年的旧做法（58）**：TTM PE 取 90 个交易日的均值 ± 1 个标准差，乘以 EPS TTM。2021 年案例里的估值区间就是这么算的。
4. **计算区间**：
   - 价值交易价格 = PE 下限 × EPS ～ PE 上限 × EPS，当前财年和下一财年各算一遍。
   - **中位价格 = 中位 PE × 当财年 EPS = 财年末的公允价**。持仓成本低于中位价格就算占便宜（79）。
   - 下一财年中位价减当财年中位价 = 理论利润空间。
5. **定性**：
   - 市价 < 当前财年下限 → 低估。越接近下限越是“黄金坑”。
   - 市价在区间内 → 合理波动。
   - 市价 > 上限 → 高估，不追（追的是下一年业绩加上 PE 继续维持高位，胜算不大）。
   - **PE 上限对应的价格不能当目标**，热度不高的股票（如银行）尤其如此（79）。
   - **EPS 在增长轨道上的，别指望跌到区间底部**（ASML 区间 406–864，跌到 406 说不通）（79）。
6. **只做一个财年**：下一财年只作参考，每季度都会变。每季财报月更新一次表（79）。

## 3. 特殊情况（他明确说过的）

| 类型 | 处理 |
|---|---|
| 暂时受冲击、一定会复苏（如疫情后的航空） | **用下一财年区间布局**：DAL 22 财年中位 26、23 财年中位 63，按 23 财年在强支撑止跌时拿（79） |
| 当年衰退、下一年重回增长（如 2022 年加息初期的银行） | 当年跌得越多拿得越多，做的是下一财年，不追高（79） |
| 中位价远高于市价但业绩不稳 | 可能是假象：EPS 预期还没反映即将到来的支出（如 C）。不当低估，跟着财报再看（79） |
| 衰退型（下财年 EPS < 本财年） | 没建仓的不考虑。坚持要做只能守均值回归 ≥1 年，赌再下一年 EPS 回升 |
| EPS 为负或极低的成长股 | 不套估值，以技术面为主：有右侧做右侧，左侧等成长性回来 |
| 高估的高成长股 | 当前 PE 高、前瞻 PE 低很多 = “按今年高估、按明年合理”，前提是增速能保持（61）。风险在财报：营收或指引一掉链子就大跌 |
| 业绩走弱的弱势股 | 即使低估也不下手 |
| 大宗商品、生物医药 | 基本面难把握，只参考技术面 |
| REIT、公共事业 | 跟利率走；低估时守得住到下一年，均值回归概率高 |
| 传统股息股 | 买的是股息，股价增长有限，替代选项是标普 |
| 资管类 | 相当于买主动基金，前瞻估值难判断，不了解就别碰 |
| 能源股 | 油价下行、市场希望能源降价时不要动 |
| 未盈利重资本公司 | 生死取决于融资环境 |
| 排雷 | 有一次性收入撑起利润（如 TSLA 2020 的监管积分）；低基数造成的高增速；负债超过资产 130–150% 或 ROE 为负（02、69） |

### 未盈利股怎么看 PS（88、116、61）
- 他的原话只有三条：
  - 未盈利但销售高增长的，用 PS 和**同行业**比：比同行高偏贵，比同行低偏便宜，只得出大致方向（88）。
  - 营收和盈利能力变化不大时，和**自己历史**的 PS 波动范围比，按均值回归判断（116）。
  - 和 5 年平均比，剔除 2020 年（61）。
- 他没给“几倍算便宜”的阈值，也没给 PS 区间的定价公式。**所以 PS 不能像 PE 区间那样算出价值交易区间**，输出里只写“相对同行偏贵/偏便宜”“相对自身历史偏高/偏低”。
- 同行要选**业务最像的**（他的例子：造车比造车）。Yahoo 的细分行业分类很粗，同行要自己挑，并在输出里列出来、写明是自选。
- 比的时候要同时看增速：PS 低但增速也低，不等于便宜。
- 这类股票的结论按第 3 节“EPS 为负或极低的成长股”：以技术面为主，有右侧做右侧，左侧等成长性回来；仓位按风险回报小仓位做（88）。

## 4. 从估值到下单（交给 02 支撑、05 仓位）

- **下手点 = 中位价附近或以下，叠加最近的大块筹码强支撑**（79，TSM：中位 120、强支撑 112–124）。只看强支撑；在支撑区内要看到止跌和大量抢筹。
- 强支撑覆盖中位价时，**在中位价下方再等约 10%**（BAC：中位 43.4，在 40、39、38 分批）（79）。
- 在区间内、在支撑上、有止跌 K 线 → 先买底仓，接近支撑下沿再分批加。强支撑落在估值区间**下方**更好（26、27）。
- **结构破了，技术面优先**：
  - 跳空跌破支撑进入估值区（PPG）→ 可能有看不到的信息，估值可能下调，等更低的一层（27）。
  - 财报前跳空跌破均线、EPS 预期环比下滑（ITW）→ 不做（26）。
- 先算基本面允许回调多少（例：PE 回到 2019 年水平，AAPL −10%），再在这个范围里找支撑挂单（61）。
- **仓位跟估值差走**（61）：
  - 高估股第一次建仓只买一点，预计还会跌 30%。
  - 低于价值区就越往下挂得越多（APD 268 / 246–249 / 237–239；MA 2% / 2% / 4%）。
  - 持仓成本要能扛住回调 30%，回调后 PE 仍在历史正常水平。
  - 没底仓的高估股不追；有低成本底仓的在支撑位加或滚动。
- 买入后只剩一点股息可吃 → 不如用现金做期权（79）。
- “风险是涨出来的，机会是跌出来的”只对有价值的股票成立（79）。
- 业绩上来了，计划价位跟着上调（237）。

## 5. 辅助方法：各自只回答一个问题

| 工具 | 用途 | 不适用 |
|---|---|---|
| PEG（59、69） | 只用来横向比业务高度重叠的同行（AMD 对 INTC，不比 NVDA）。板块：先选 EPS 增速 > 标普，再选 PEG < 标普 | 不能给单只股票定价；不认“PEG<1”这条；要求 EPS 为正且在增长 |
| PB + ROE（60） | 重资产同行二选一，ROE 高的胜（BAC 胜 WFC） | 科技股 |
| ERP（116） | 机构会不会抢 | EPS 为负；EPS 趋势向下（“那不叫便宜，还可以更便宜”） |
| CAPM（261） | 今年的预期回报和实际已涨幅比；量化红线（TSLA 2025-10 约 470） | EPS 衰退、营收不增长、Beta < 1 |
| DCF（88、56） | 理解利率为什么压估值；保守 DCF > 市值作为旁证 | **买卖决策不用 DCF，用追踪 PE**（56）。机构目标价是远期 DCF，只作参考 |
| 分析师评级（56） | 默认偏高；大投行调成 Hold 并降目标价 = 隐晦看空；降级下跌通常短暂，可以反向操作 | 覆盖分析师少于约 10 个 |

### ERP（股票风险溢价）的具体算法（116）

- 预期收益率（益本比）= EPS ÷ 股价
- ERP = 预期收益率 − 美国 10 年期国债收益率
- 机构要求：1 年期约 3%-3.5%，30 年期约 5%-5.5%。**低于 3% 缺乏吸引力**。
- 反推目标价：目标价 = EPS ÷（10Y 收益率 + 目标 ERP）
- EPS 下降、10Y 上升都会压低 ERP；价格下跌会抬高 ERP，所以跌到一定程度会有资金抄底。

### 利率（87、88、61）

- 10Y 上行会推高折现率，所有股票估值都承压，未盈利成长股最重。
- 零利率给出的溢价，确定加息后会回吐；市场一般提前约半年开始反应。
- 高通胀年份，比自身历史估值高约 3% 算合理，再多就是流动性推出来的。

## 6. 指数层面

- 标普用前瞻 PE 18-22 倍 × 前瞻 EPS 得出区间（2026-11：7000-8500），下沿留余量。
- 市场提前 6–12 个月交易。年底不应低于**下一年**区间下沿，除非下一年 EPS 被大幅下调；低于就是机会（237）。
- 决定方向的是盈利，不是情绪。EPS 没有大幅下修时的大跌，属于基本面与价格背离。
- 盯标普前瞻 52 周 EPS 和前瞻营业利润率（Yardeni）有没有拐头，利润率见顶下修大约领先股价一年（305）。
- 盯对 EPS 增长贡献最大的几只（2026 年为 NVDA、MU、AVGO，占 2027 年增长 40-45%）。
- 看多家数据提供商的综合数据，不看单个投行。
