# 支撑与压力：怎么画、怎么评强弱

来源：会员第 283 期（2026-04，强弱七原则）为主，加上 10、11、12、113、161、213、222、224、270、282 期。

## 核心认识
- 支撑压力不是 100% 预测，只是把胜率从 50:50 提到 60:40、70:30。它有效是因为用的人多，机构算法也在用（283）。
- 破位、突破、修复都以**收盘价或开盘价**为准，不看盘中；盘前盘后、夜盘价格都不算（272）。
- 不靠单一工具：多数工具指向同一方向（约 10 个里 7-8 个）才下结论（213、16）。

## 0. 先过滤
- 日均成交额 < 约 2000 万美元算勉强，< 1000 万直接删，不研究（213、224）。
- 只用在有效市场：小市值、消息驱动、妖股、不少中概股不守规则（22、213）。

## 1. 周期
- 美股最小看日线。周线看区间和大趋势，日线定价位和进场（23、283）。
- 1h、30 分钟只看关键位的争夺细节；30 分钟以下不看（23）。
- **看什么周期做什么周期**：小周期的突破要改变了日线结构才算数；大周期压制小周期（23）。
- 画位时去掉均线，只看裸 K（12、213、222）。

## 2. 先找“点”：结构
1. 判断结构：上行、下行还是震荡。**震荡里不用斐波那契**（12）。
2. 用最近一段有效的高低点拉斐波那契。高低点只隔几天的不算趋势；结构套结构就升到周线、月线。算出的位置太密（处处是支撑）就换更大一级、最好已经测试过 61.8% 的结构（12、113）。
3. 常用 **38.2% 和 61.8%**，50% 偶尔用，23.6% 不用。38.2 轻度回撤，50 中度，61.8 极限（12、113）。
4. **61.8% 定趋势（收盘价）**：
   - 收盘跌破 61.8% = 破位：上行结构结束，反弹是卖点，下一步看 100%（前低）；再破就换更大结构算 61.8% 和 100%。“可以看到”不等于“必须跌到”（283、12）。
   - 盘中跌破、当天或次日收回 = **刺破**，支撑仍有效（12）。
   - 下行结构里，反弹到 38.2/50/61.8 被压只是**反弹**；收盘站上 61.8% = **反转**，目标前高。破位后把跌破的那段倒过来画，它的 61.8% 就是确认反转的位置（283、113）。
5. 其他点：趋势线、通道上下沿、旗形/杯柄线、头肩/W/M 颈线、前高前低、整数关口（283、113）。
6. **斐波那契扩展**（算目标）：只在结构没破时用。A 趋势低点、B 高点、C 回撤低点；每个扩展位都是压力，50%-61.8% 决定能不能回到前高（113）。

## 3. 再找“区间”（按使用顺序）
1. **密集交易区**（222）：就近原则，近的失效再往前找。先用测试过 2-3 次以上的影线框出范围，范围里实体最密、K 线最多的一段最强。回看 1 年内最好，2 年可用，3 年以上不可靠。主区间下方是空档时，下沿特别关键：跌破下面没人有成本，跌得快。
2. **增量 K 线**（213、222）：近期放量、实体长、影线短的 K 线（排除星线、锤子线、流星线、滞涨线）。标实体上沿、中间、下沿，中间是多空分界。下方的增量阳线是支撑，跌破变压力；上方的增量阴线是压力，被吞没变支撑。适合没有横盘平台的急涨急跌段。
3. **有效高低点**（224）：短线、微观。日线最近 1-6 个月，用影线极值，**至少 3 次触及、彼此相差 1% 以内**（2 次不算）。跌破 = 超出影线 1% 以上或跳空低开。回踩不破又被买起来 = 买点。
4. **辅助工具，不单独用**：
   - 筹码分布：只看方向，不用券商软件给的支撑压力数字（11）。
   - 5 日滚动 VWAP（hlc3）：机构成本。首次放量跌破 = 机构在卖；首次放量站回且均线拐头向上 = 可能反转（270）。
   - 季末 SPX 期权领口（只用于指数）：约 5% 虚值的长 Put = 支撑，3-5% 虚值的空 Call = 天花板；指数波动超过约 5% 时才有意义（282）。

## 4. 强弱：小 / 中 / 强 / 超强
**七原则（283）**：
1. 点 > 区间；点落在区间里时，点所在的一侧更强（100-120 区间、61.8 在 111 → 111-120 更强）。
2. 交易时间越长的结构点 > 时间短的结构点。
3. 交易时间越长的区间 > 时间短的区间。
4. 时间相近时，成交量大的 > 成交量小的。
5. **时间优先**：3 个月横盘 > 3 天放量。
6. 强弱是模糊的，不必精确量化。
7. 强弱是相对的，会随测试变化；只和自己比，不跨股票比。

**补充规则**：
- **共振最强**：斐波那契 + 通道下沿 + 震荡区下沿 = 非常非常强（283）；密集区下沿和上升趋势线交叉 = 关键防守位，也是潜在好买点（222）。
- 放量的**反复测试让支撑变强**（小/中 → 强）；他没说过测试会削弱支撑（283、224）。
- **天生偏弱**：没有横盘的快速拉升段、缩量穿过的空虚地带、交易时间短且量小的顶部、缩量平台（283、161、222）。
- **回踩增量 K 线的深度**：停在上沿 = 很强；停在中间 = 强；穿过下沿 = 被套，角色反转（213）。
- **角色互换**：跌破的支撑变压力；压力要**收盘站上区间上沿**才变支撑。回到下沿上方只是破位后的反弹，不算修复（222、272）。
- **结构全部被破坏**（关键位全失守、创新低）：没有点，只看区间，先比横盘时间，再比成交量（283）。
- 重点区分“强”和“中”，小支撑意义不大。“超强”只出现在多年级别、标“长线”的区间上，没有明确定义（283、213）。
- 区间下沿写宽一点（写 315 而不是 320）；右侧突破位设在区间上沿略上方（171 → 173）（283、213）。
- 他的区间是稳定的地图：同一只股票的档位会沿用几个月，随测试调整（213、222、224）。

## 5. 成交量
- **纯相对、目测**：和前一根比，或和最近平均比；不给倍数，不规定均线长度（10、213）。
- 放量突破 = 有效；缩量突破 = 等，可能是陷阱。放量跌破 = 趋势转坏；缩量跌破 = 等，可能是诱空（10）。
- **缩量涨、缩量跌都是“耍流氓”**，持续性有限，它穿过的价格区没有支撑压力（161）。“放量破位下跌是最真实的下跌”（161）。
- 缩量还没跌破关键位时：守住，止损放在支撑下方，不在支撑底部割（161）。
- 放量后收在成本区上方 = 有效突破，将来是支撑；收在下方 = 有人被套，将来是压力（10）。
- 缩量形成的形态是“待定”，不是无效，后面放量可以变有效（10）。
- 周线价涨量缩 = 顶背离风险，急涨可能是赶顶（213）。

## 6. 特殊情况
- 快速拉升、连创新高、没有横盘的区间没有强支撑，涨得快跌得也快（283）。
- 急涨跳空后强支撑离得很远，后面只有两种走法：缺口上方筑新平台，或大幅回踩后再涨（283）。
- 缺口区都是支撑压力；旧缺口只有没被交易过的那一段算支撑（15、27）。
- SPY 和 SPX 有偏离时，给 SPY 点位并留余量，避免期货或盘中误判。
