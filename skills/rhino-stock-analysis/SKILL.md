# Rhino 式个股分析

把 Rhino 的分析流程套到**当下的真实数据**上。学的是方法，不是他说过的点位：他过去给的价格只能当历史参考，不能当今天的结论。

## 铁律
- **数字必须来自当下的真实数据**：用 WebSearch/浏览器查，或请用户提供。查不到就写“缺数据”，绝不编 EPS、PE、价格。
- 每个结论都要说出依据走的是哪一步、哪条规则（如“不买第 4 条：缩量反弹”）。
- 输出结尾注明：基于 Rhino 公开/会员节目方法的个人学习工具，不构成投资建议。

- references 里出现的具体点位、估值数字都是**带日期的历史示例**，只用来学方法，不能搬到今天的结论里。
- 用户问“能不能加仓/要不要卖”时，先问（或从上下文找）他的**成本、仓位占比、投资周期（长线/波段）**。Rhino 的建议因人而异：重仓、轻仓、空仓的做法不同。

## 第 0 步：先跑数据脚本

```bash
python3 <本技能目录>/scripts/rhino_data.py TICKER [--peers A,B,C] [--pe-band 低 高]
```

- 本技能目录就是这个 SKILL.md 所在的文件夹（一般是 `~/.claude/skills/rhino-stock-analysis`）。
- 需要 yfinance。`python3` 里没有时，先找已有的虚拟环境（如 `~/rhino-finance/.venvs/quant/bin/python`），都没有再 `pip install yfinance`。
- 输出一份数据单（Yahoo Finance）：大盘结构（QQQ、SPY、DIA、IWM、SOXX、VIX、10 年期收益率、11 个板块 ETF）、市值和成交额门槛、EPS/营收预期和修正、估值辅助（PE 区间 × EPS、P/S 历史、同行表）、板块跌幅排名（不买第 6 条）、RSI6/24 和背离状态、均线、MACD、5 日滚动 VWAP、最近 3 根 K 线的形态判断、九转计数、5 日均量方向、波段和斐波那契（含 52 周高点以来的反转确认位）、密集交易区、增量 K 线、有效高低点、近 2 年的箱体边缘、未回补缺口、周线。
- `--peers`：亏损股一定要自己挑业务最像的同行（Yahoo 的细分行业分类很粗）。
- `--pe-band`：盈利股按 `01-valuation.md` 定好 PE 区间后再跑一次，脚本会算出两个财年的价值交易区间和中位价。
- 数据单只给事实。强弱、命中哪条、是不是买点，按 references 判断。标 DEFAULT 的阈值是脚本的默认值，不是 Rhino 原话，用到时在输出里注明。
- 脚本跑不了时退回手工：用 WebSearch 查 EPS 预期，用 Yahoo chart API 取 K 线，自己算。

## 脚本给不了、需要另外找的数据
| 数据 | 用于 | 来源 |
|---|---|---|
| 该股 2018-2019 年 Non-GAAP PE 高低位 | 估值 PE 区间 | companiesmarketcap（macrotrends、gurufocus 常返回 403）；拿不到写明是近似 |
| 当天新闻、财报内容 | 不买第 7、17 条，跳空原因 | WebSearch |
| 标普前瞻 EPS（多家数据商综合） | 指数估值：前瞻 EPS × 18-22 倍 | WebSearch（FactSet、Yardeni、LSEG） |
| 社群热度 | 不买第 10 条 | 没有数据源，标“由用户自判” |
| CTA、伽马、对冲基金敞口、涨跌家数 | 大盘环境 | 没有免费源，拿不到就跳过并注明 |

## 流程（按顺序，每步读对应参考文件）

1. **大盘环境**（`06-market-context.md`，数据单第 1 节）：现在是上行结构、反弹结构还是破位？适不适合动手？泥沙俱下时结论默认是“等企稳”；大盘破位时个股反弹先当下跌中继。
2. **估值**（`01-valuation.md`）：
   - 用 PE 区间 × 两年 EPS 算价值交易区间和中位价，判断低估/合理/高估
   - 判断是否衰退型、是否属于特殊类别（未盈利、大宗、REIT…）
   - 需要时补一个 ERP
3. **支撑压力**（`02-support-resistance.md`）：先过流动性门槛；先点（斐波那契 61.8% 定结构）后区间（密集交易区、增量 K 线、有效高低点），用七原则给 3-5 档支撑和上方压力标小/中/强/超强。以收盘价/开盘价确认。
4. **不买清单**（`04-no-buy-checklist.md`）：18 条加补充规则逐条过，命中任何一条就写出是哪条，结论改为“现在不买，等 X”。数据判断不了的（第 8、9、18 条）标“由用户自判”，缺数据的标“缺数据”。
5. **买点**（`03-buy-points.md`、`07-indicators.md`）：先定左侧还是右侧（估值是开关）；在强支撑上等什么止跌形态（按有效性排序），或等哪种突破/回踩；对应 9 种买点里的哪一种，给出具体触发条件。指标只做过滤和否决。检查盈亏比 ≥ 1:1。
6. **仓位与计划**（`05-position-risk.md`）：分几批（235/334…）、每批放在哪档支撑、止损位（支撑下沿）、盈亏比（写出买入、止损、目标三个数）、能否扛 30%-40% 振幅、没买够就涨了怎么办、什么情况下计划作废。没有估值区间的股票不做左侧长线分批，见 05。

### 5. 买点与触发条件
### 6. 情景推演与仓位计划
- 若 <收盘守住/跌破/突破 X> → <判断> → <动作>

情景推演要写成 Rhino 的口吻和结构：条件（以收盘价为准）→ 结构判断（上涨结构/反弹结构/重回震荡/转熊）→ 对应动作（等止跌形态再买、反弹到 X 减仓、不见兔子不撒鹰）。

## 已知局限
- 方法来自 55 期会员教学：估值 17 期，支撑、止跌形态、买法、指标 38 期。仓位管理、见顶和卖出、期权、心态还没系统处理。
- 第 9 种买点的“超卖（RSI 大于 80）”已核实是口误，按 RSI6 < 20 处理（见 `03-buy-points.md`）。
- PE 区间默认用该股 2018-2019 年的 PE 高低位，有几种例外（见 `01-valuation.md`）；拿不到 2018-19 年 Non-GAAP PE 时写明是近似。
- 亏损股的 PS 他只给方向判断，没有阈值，不能算出价值区间（见 `01-valuation.md`）。
- “近期新低”“很近”等词他没量化，脚本和参考文件里的 DEFAULT 是默认值，输出时注明。
- EPS 修正只有 Yahoo 的 7/30/60/90 天前数据；他要求保留前 4 个季度对同一财年的预测，需要自己长期存档。
- 资金面数据（CTA、伽马、对冲基金敞口）没有免费来源。
